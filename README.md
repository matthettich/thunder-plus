# ...Thunder Plus

...Thunder with **…waves** built in: a modular synth whose Out modules feed a new oscillator type in the layers. ...Thunder is part of this app now; its old address (https://matthettich.github.io/Thunder-/) forwards here.

**Mobile and Desktop.** ⚙ Settings → App → **Mobile** switches the app between ...Thunder and ...Thunder Plus. Mobile (...Thunder) shows only Synth and Tracker, hides the …waves and …chains editors and puts the tracker in PAD input; Desktop (...Thunder Plus) shows all four screens and goes back to the input you used there. …waves layers and …chains effects play in both, live and in renders, so the same kit and project files open and sound the same either way. Mobile is the first choice on a touch screen; the choice is saved per browser. On Mobile, **Show …chains on Mobile** and **Show …waves on Mobile** (under the Mobile tick, both off at first) bring back one editor or both, for a big screen like the unfolded Fold.

**Coming from the old ...Thunder.** Where ...Thunder left a song and kit in the browser, the first time this app opens it offers to open them, saving its own song and kit to a project file first. **File → Open ...Thunder's saved work** does the same any time.

**Using …waves.** **…waves** is a third screen next to Tracker and Synth: the modular patch editor (the same as https://matthettich.github.io/waves/). The kit holds one waves patch, saved into the kit as you edit; switching to another screen pauses the editor's sound and re-renders the pads that use it. In any layer, choose **…waves patch** as the oscillator and pick an **Output** (Waves In 1–8): the layer plays whatever the patch's Out modules send to that output. The patch is played for one note, held for the pad's Gate (synth slots: up to Max len), then the layer's envelope, filters and the pad's effects apply as usual. Tune 0 st plays middle C (C4) into the patch's Host In, so Tune and the pitch envelope move the patch's pitch. Sequencers and LFOs inside the patch run during that note, at the song's tempo.

**New sounds (Oct 2026).** Effects on pads, track FX slots and in …chains: Flanger, Phaser, Tremolo, Overdrive, Wavefolder, Auto-wah, Pitch shifter, Ladder filter, Cross-mod, Space reverb, Lo-fi, Drive, Air, Room reverb, Comb resonator, Transient shaper, Trance gate, Multiband squash, Frequency shifter, Vinyl, Dub tape, Speaker cab and Tube (sources in `THIRD_PARTY_NOTICES.md`). Synth oscillators: Super saw, Phase dist., Chip, Formant, VOSIM and Grains. Mod LFOs and the mod sequence can sync to the tempo, with S&H and smooth-random shapes. …chains adds Steps, Clock (synced gates and ramps) and Repeat (beat repeat, reverse, tape stop).

**More sounds (Oct 2026, part 2).** New effects, on pads, in track FX slots and as …chains/…waves modules: Spectral (blur, freeze, gate, robot, whisper, shift), Extreme stretch, Convolution reverb (rooms, halls, plate, spring, gated, reverse, cab, telephone, or the song's own IRs), Pitch correct, Vowel filter, Rotary speaker, Granular delay, Reverse echo (and reverse-reverb swells) and Envelope filter (it can follow the sidechain). Spring, Plate, Ensemble, Dimension, BBD delay and Harmonizer are now pad and track effects too; Flex, Step gate and Retrigger are pad effects and modules; Pitch delay and Pitch reverb are modules. New synth engines: Vector (four waves on a joystick, or a wave sequence in time with the song), Scanned (a vibrating ring scanned as a wave), Resynth (load a sample: it is rebuilt from its partials at any pitch) and Bytebeat (one-line formulas of t). A Chaos layer oscillator, and for the modular editors Chaos and Bytebeat sources plus a Random generator and a Function generator (based on Mutable Instruments Marbles and Tides). The Add effect menu on the Synth page is grouped.

**Song impulse responses.** ⚙ Settings → Song settings… → Impulse responses → Load… takes up to four impulse responses (up to 8 s, stereo or mono) for the Convolution reverb's Type: Song IR 1–4. They are kept with the song like samples, and project files carry them.

**…chains controls in the bottom panel.** In …chains, right-click a control → **Add to the bottom panel**, or right-click a module → **Add all of its controls**. They appear in the bottom panel's **…CHAINS** section (between INST and FX, where …chains sits in the signal flow) for the track whose chain they're in, and move the sound live. A dot marks them in …chains. Right-click one in the panel to remove it or show its module. When the panel has more than fits, it scrolls sideways.

**Break chopping.** On an instrument (INST), SLICES cuts its pad into equal parts or at its hits, and notes pick the slice (C-4 is the first). SYNC fits the loop (BEATS long) to the tempo by REPITCH, STRETCH (pitch kept, smooth grains) or LOOP (pitch kept, tempo-synced little loops: the ramp-LFO trick). › GUESS BEATS and › PLAY SLICES help set it up.

**Separate from ...Thunder.** Thunder Plus saves its kit, song and settings under its own names. The first time it opens, it offers to bring over ...Thunder's kit and song (saving its own to a project file first); once Plus holds its own copy with every sample, ...Thunder's old kit and song are removed from the browser to free storage. Its offline cache is its own too.

**Desktop app.** The Electron build serves the app from its own `app://thunder/` address instead of opening plain files, so the …waves editor frame can load its sound engine and save into the kit as it does on the web. Build it as below (`npm start` to try it); `waves/` is copied in with the rest.

**Files.** `waves/` holds the …waves editor and engine (`waves/waves-worklet.js`, from the waves repo); Thunder Plus loads the same engine to render patches into the pads, using the Plaits, Elements and effects code already in `index.html`.

**One app, one repo.** ...Thunder used to be a separate build of this app in the `Thunder-` repo; since 13 Oct 2026 it is the Mobile setting here, and that repo only forwards its old address to this one.

**Running it locally.** This is a plain web app with no build step. Serve the repo root over HTTP, then open the pages:

```
cd thunder-plus
python3 -m http.server 8734 --bind 127.0.0.1
```

- **App:** http://127.0.0.1:8734/index.html
- **…chains patch editor** (where the Vocoder and the other …chains modules live): http://127.0.0.1:8734/chains/index.html
- **…waves patch editor:** http://127.0.0.1:8734/waves/index.html

Open them over HTTP, not `file://` — the editors load their sound engine with `fetch`. Picking the work back up after a break? See [`HANDOVER.md`](HANDOVER.md) for the current state, how to validate (there is no test suite) and the open items.

# ...Thunder

An 8-pad drum synth and 16-track tracker for the browser, built for a Galaxy Z Fold 6, for making one-shots to use in Koala or SunVox. It uses the Minimal skin from ...Seeds.

## What it does

- **16 slots (8 drum pads, 8 synths; 32 with a voice per track), 8 layers each.** Every layer has its own oscillator, pitch envelope, amp envelope (A·H·D or ADSR), low-pass and high-pass filters with an envelope, delay and clap-style bursts. On top of the layers, each voice also has a voice-wide pitch envelope, a low-pass filter with its own envelope, and an amp envelope (A·H·D or ADSR), each with an Amount slider — they shape all of that voice's layers together from the Voice pitch, filter & amp card on the synth page.
- **Oscillators**
  - Standard: sine, triangle, saw, square, pulse, click
  - Wavetable: a morphing oscillator — Position blends sine → triangle → saw → square, Formant tilts the spectrum, Bend warps the cycle, plus up to 8-voice unison with spread, a sub and noise. All generated in-app (no bundled wave files)
  - FM: 2-op, feedback, metal, cross-mod, plus a standardized family sharing the same core controls — Algorithm and Feedback: 4-op, 6-op, Genesis (a 4-op YM2612-style chip with its 9-bit DAC), Sound Blaster (a 4-op OPL-style chip with half-sine operators) and an arcade 4-op
  - Additive: harmonic, odd, membrane, bell, bar, chord
  - Noise: white, pink, brown, blue, 808 metal, digital LFSR, crackle, sample-and-hold
  - Plaits: all 24 models of Mutable Instruments Plaits (synth voices, 6-op FM, chords, speech, strings, modal, drums), run from the original code
  - Elements: Mutable Instruments' modal voice, with bow, blow and strike exciters and modal, string or strings resonators
  - Samples loaded from audio files
  - PWM sampler: a sample (or a built-in cymbal) played like old hardware, with a clock of 2–32 kHz that follows the pitch and no smoothing, through 1-bit PWM (PC speaker / Atari), NES DPCM, or 2–8-bit PCM (6-bit is the TR-909 cymbal sound). Load sample on a PWM layer keeps its clock and mode
- **Samples.** Load an audio file (up to 30 seconds) into any layer with Load sample, then pitch, reverse and filter it like any other layer. Samples are kept in the browser's IndexedDB storage, so long ones survive a reload; kit and project files still carry them inside.
- **Voice modulation.** A matrix of 3 LFOs, 3 envelopes and a 32-step sequencer, each routed to one destination — pitch, level, low-pass or high-pass cutoff — with a signed amount, applied across all of the voice's layers. All amounts start at zero (off). Built entirely in-app. The **Mod envelopes** section has a **Reset to defaults** button that restores the pitch, amp and three mod envelopes to their factory values.
- **Glide, legato and mono.** Per voice: Glide slides the pitch from the last note, and Mono + Legato retunes the sounding note instead of retriggering. Applies to live playing (keyboard, pads, MIDI).
- **Microtuning (song).** A cents offset per pitch class, with Equal, Just, Pythagorean and Meantone presets or any custom values, applied to live playing and the tracker alike.
- **Export.** Mono WAV, 44.1k or 48k, 16 or 24-bit, normalised and tail-trimmed. Save one pad or all 8 as a zip, or share straight to Koala on Android. Optionally add the note to the file name (for example `03 Pluck C3.wav`).
- **Effects per pad.** Up to 6 in any order, with a tail length: Rings resonator, Clouds (granular, stretch, delay, spectral, with a hold-the-tail switch), Airwindows Density saturation and ToTape6, DaisySP chorus and bitcrush.
- **…chains and …waves editing.** The module list is grouped by what modules do (In and out, Sound, Mix and dynamics, Effects split into filters, drive, modulation, delays, reverbs and more, then Control), and each group has its own colour, on the list and on the modules in the patch, so a patch reads at a glance zoomed out. Hold **Option** (Alt on Windows) and drag a module's title bar to copy it (or the selection) and drop the copy where you let go. The **Mixer** (and …chains' **Stereo mixer**, stereo pairs with level and pan) has an **Inputs** setting from 1 to 16. In …chains and …waves every jack has a thin level meter beside it. The **?** on each module's title bar says what the module does and gives an example of using it (hover with a mouse, or tap it; tap again or press Escape to close).
- **…chains (modular effects).** Each **Track In** shows an **IN** meter (what that track sends into the chain) and each **Chain Out** an **OUT** meter (what comes back), so you can see a track is feeding its chain while the song plays. A Track In's track list marks the tracks that already have a chain; opening …chains from the tracker shows the chain of the track you were on. A patch editor of modules — Track I/O, VCF/VCA/Mixer, a 2/4-pole driven **Blades** filter, a **Vocoder** (In L is the carrier, In R the modulator: Talkbox, 4–64 band banks or a spectral cross-synthesis), eleven effects plus a **Meta modulator** (crossfade/ring mod/wave fold/comparator), **Phaser**, tempo-synced **Ping-pong delay** and a stereo **Width** control, and LFO/ADSR/Random/Attenuverter — plus **audio→CV**: Envelope Follow, Gate Extract and Pitch Follow turn sound into modulation, and Slew, Sample & Hold and Quantizer shape it. Every slider has a modulation jack (the slider sets the centre, the signal swings it across its range), from the LFO, envelopes, an audio follower or any other signal.
- **Sidechain** (21 Oct: one **Source** everywhere, no mixer bus). Every compressor, gate, envelope filter, Bus Comp, Glue Comp and Sidechain In — in …chains and as track or master effects — has a **Source**: **Self** (its own input; **Off** on a Sidechain In), **Send 1–8** (what a Sidechain Out sends), or any **track** (that track's own sound, before its effects and fader, so a muted kick still pumps). So track 3 can be ducked by track 2 while track 4 is ducked by track 6. Something patched into a module's SC input wins over Source. The Mixer's **SC** row is now a light: it shows **ON** under a track that something listens to; Enter / EDIT on it says what. A **Sidechain In** module gives the source's sound, an **Envelope** that rises with each hit and a **Duck** output that dips with it (patch Duck into a VCA's CV to pump a sound), with Sensitivity and Release; **Sidechain Comp** (Threshold/Ratio/Attack/Release/Makeup/Mix) ducks by its Source or its SC input. Older songs that used the mixer's sidechain bus move to the lowest track that fed it, with a one-time note saying so. Each track has its own **Track In** and **Chain Out** pair: turning a track's CHN on in the Mixer adds that track's pair (wired straight through, in a column below the rest) and stays in the Mixer, so chains are per track and toggling one never disturbs another; the next time …chains opens it fits the patch so you see every pair. The output follows its own input. Patching a new Track In and Chain Out for a track in …chains turns that track's CHN on for you. If a track already has a chain, switching its CHN on runs it through that chain again; picking that track in the editor jumps to and highlights the existing chain. Control inputs aren't limited.
- **…pump mastering effects on buses and the master** (23 Oct). The nine pump plugins (EQ, COMP, LIMIT, CALM, TONE, BAND, WIDE, HEAT, METER: the same DSP as the VST3/CLAP builds) are track effects in the FX picker's **Mastering (…pump)** group, on bus tracks and the master only. Each shows its main settings as the usual hex rows (EQ, BAND, WIDE and HEAT pick a **BAND** for their per-band rows), keeps all of the plugin's settings with the song, and has **› PRESET** (the plugin's factory presets: Factory, Sources, Chains) and **› OPEN** (the plugin's own full window, as a pop-up: EQ, COMP, LIMIT and METER so far; the others in a later update). The window looks and works like the plugin (its curve or history display, every control, drag / Shift-drag / double-click to type / Ctrl-click to reset / wheel, the plugin's presets plus your own, A/B, BYPASS = the slot's ACTIVE, Thunder's undo), with live meters and spectra while it is open; EQ adds bands with a double-click, solos one with Alt held on its node and listens to a range with Alt held on empty space. Light or dark follows the skin (the window's DARK key overrides it). On a computer several can be open, moved and resized; on a folded phone one fills the screen in a narrow layout (double-tap types a value, long-press is the right-click menu). COMP and LIMIT show the dynamics display on the FX stage, METER its loudness. CALM, TONE, LIMIT and the linear-phase modes add latency: fine on the master (renders line it up), but a bus plays that much late against the other tracks. LIMIT and HEAT start with oversampling off to spare the phone's CPU.
- **Buses in …chains** (20 Oct). Set a **Chain Out** to a different track than its **Track In** and the chain is a bus: several Track Ins → a Mixer → a compressor → Chain Out on a free track makes a group bus. Each source track is heard after its own effects, fader and pan, plays only through the bus (unless its own chain also comes back out on itself), and the bus track's fader and effects level them all. Soloing the bus keeps its sources; soloing a source keeps its bus. A bus track looks a little darker on every screen (Arrange, Song, Pattern, the Mixer column) and says **BUS** where it would say MONO or POLY; a source heard only through its bus shows **BS** in the Mixer's CHN row; and the first time you start programming on a bus, a note says what it is (its own notes do play, through its chain). In renders, a bus track renders with its sources; a source heard only through its bus has no stem of its own (it's in the bus's stem), so the stems add up to the mix.
- **Sidechain Out** (20 Oct): sends what's patched into it to **Send 1–8**. Anything with its **Source** on that Send hears it, in any track's chain (a block, ~3 ms, later), so one bus can duck another. A Sidechain In (or any Source) set to that Send hears it. Any Source can also be a track: the app wires in only the tracks you pick (up to 32 different ones at once).
- **Bus Comp** and **Glue Comp** (20 Oct), stereo, in …chains (and …waves), and as track, master and pad effects: Bus Comp is the punchy console bus compressor (Ratio 2/4/10:1, stepped Attack, Release with Auto); Glue Comp is the smooth one (RMS, wide Knee, Range, Auto release, Soft clip). Both have Source (Self, Send 1–8 or a track) and an SC input, SC high-pass, Makeup and Mix, and show their gain reduction.
- **MIDI.** Plug in a controller, tap ⚙ Settings → MIDI → Connect MIDI. On the Synth page pads 00–07 answer notes 36–43 with velocity; other notes play the selected synth. **Notes in** picks the input and channel that play notes and move knobs (the others are ignored, so gear that echoes ours can't play the pads). **Keys play** (in the tracker): the keyboard plays the instrument you're on, the INST screen's or the cursor row's in a phrase, pitched from C-4 = MIDI 60 and held while the key is down; a MIDI instrument plays its gear, with pitch bend, aftertouch, program change, sustain and every CC that isn't learned to a slider passed through (or choose **The pads** to keep the Synth page's mapping). Typing a note with the computer keys holds it the same way until the key is let go. **Learn**: tap any pad and hit a key to give it that note (synth pads hold while the key is down), or touch any slider and turn a knob to put it on that CC. A learned knob works that slider for whichever pad, layer or effect is open, and shows its CC next to the slider's name. **Unlearn** clears the selected pad or slider; **Reset all** goes back to the defaults. Mappings are kept on the device.
- **MIDI out and clock.** Settings → MIDI has four output ports, **A–D**: pick the cable each one is on this device. On the INST screen, **OUTPUT** sends an instrument's notes to its **PORT** (MIDI: the pad stays quiet; PAD+MIDI: both) on its **MIDI CH**, with TRANSPOSE and pitch commands applied and the volume column as velocity (C-4 is MIDI note 60). The song keeps only the port letter, so it plays the same on the phone and the computer, each with its own gear. Phrase commands `CCA`–`CCD` send 00–7F to the instrument's four CC slots (INST › CC A–D, the CC numbers: 74, 71, 1 and 7 to start), and `PGM` sends a program change just before the row's note. `PSL`, `PBN`, `PVB`, `PIT`/`FIN` on a held note and fractions of a semitone go out as pitch bend: set **BEND RANGE** on INST to the gear's range. `ARP` plays one note a step. **LFO → CC:** INST › **LFO CC** gives a MIDI instrument an LFO on a CC while the song plays: SHAPE (sine, triangle, saw up/down, square, random), RATE in time with the song (1/16T to 8 bars), DEPTH, CENTRE, and RESTART (FREE runs from PLAY, NOTE starts again at each of its notes). **Clock out** sends Start, 24 clocks per beat and Stop to the ports lit (A–D) while the song plays; started partway into a block of song rows, it sends Song Position Pointer and Continue instead, so the gear jumps to the same place. With **Clock in**, the other device's Continue after a Song Position Pointer plays the song from that place (in the block the cursor is in). **Clock in** follows another device: its Start and Stop run PLAY and its tempo sets ours, kept in phase. **Delay** (one per port) sends that port's notes earlier for hardware that sounds late. **Clock from** picks the input Clock in follows; by default the first one that sends clock keeps it until it goes quiet, so two devices sending clock can't double the tempo. MIDI-only instruments are silent in audio renders (export a MIDI file for them).
- **More for MIDI instruments (INST).** **NOTE LEN** ends each note after that many ticks (HOLD: until OFF, KIL or the next note). On a poly track each note column is its own voice: a new note in a column ends that column's last note, so chords don't pile up on a hardware synth. **ECHO** repeats each note on the gear (1–16 times, ECHO TIME 1/32 to a bar, ECHO FADE softer each time, ECHO PITCH semitones per repeat). The phrase command `CSL` makes the row's `CCA`–`CCD` glide to their value (over XY ticks, 00 across the step) instead of jumping.
- **Every instrument.** **KEY FOLLOW** (on for synths, off for drums) makes an instrument follow LIVE TRANSPOSE and the song's **SCALE** (Project → Song → SCALE / SCALE ROOT: a note outside the scale plays the nearest one in it). **HUMAN TIME** (± up to 50 ms) and **HUMAN VEL** (softer by up to 90%) vary each note at random; `SED` makes it repeat. There are 64 instruments (00–3F); the instrument list shows 00–0F plus any you've used or set up. In songs made before 64, an `INS` above 0F still plays 0F, until you put an instrument past 0F in a phrase.
- **Recording.** **REC** on the tracker's top strip (F9 or Alt+R). Stopped: a note or chord from the MIDI keyboard goes into the phrase at the cursor (a chord fills a poly track's note columns) and the cursor moves on when you let go. Playing: notes land on the step they were played on, in the phrase the track under the cursor is playing, with velocity in the volume column and OFF where you let go of a synth or MIDI note; the computer keys and the keypad record at the playhead too. A take is one undo step. **CLICK** (Alt+M) is the metronome: while recording, always, or off. Settings → **Record & play** sheet: REC TIMING (STEP: the nearest step; TICKS: the step it was played in plus a `DEL`, keeping the feel), REC VELOCITY, REC NOTE OFFS, METRONOME, CLICK LEVEL, COUNT-IN (1 or 2 bars before a recording), and LIVE TRANSPOSE.
- **Live transpose.** Settings → Record & play → LIVE TRANSPOSE: a key on the MIDI keyboard transposes the KEY FOLLOW instruments as the song plays, and it stays until the next key. WHOLE KEYBOARD: every key, from C-4; KEYS BELOW C-4: those keys from C-3, the rest play as usual.
- **MIDI files.** File ▾ → **Export MIDI file** writes the song from RENDER FROM as a type 1 .mid (480 ticks a beat): a tempo track, then a track per tracker track. MIDI instruments keep their channel and notes; synth slots their pitch; drum pads one note per pad (their MIDI learn note, 36–43 by default) on channel 10, for a DAW's drum rack or the MPC. Pitch bends, echoes and CC glides are left out. **Import MIDI file…** puts each MIDI track (each channel of a type 0 file) into the track under the cursor and the ones after it, from the song cursor's row down, a phrase per PATTERN LEN steps at the song's LPB (identical phrases shared), with velocity, OFFs, chords in poly tracks, and DEL for timing with REC TIMING on TICKS; an empty song takes the file's tempo.
- **Play direction and Euclidean rhythms.** The phrase command `DIR` sets a track's direction from the next row on: 00 forward, 01 backwards, 02 ping-pong, 03 random; a phrase still plays as many steps as it has rows. Edit ▾ (or right-click) → **Euclidean fill…** spreads HITS evenly over STEPS (rotated by ROTATE) in the note column under the cursor, over the selection or from the cursor down.
- **Kits.** Kits save in the browser automatically and can be saved or loaded as `.json`, recorded samples included.
- **Drift (tape pads).** A synth-slot engine for warm, wobbly, faded pads: two oscillator lines per voice (saw and pulse with PWM, line II detuned or set to an interval, sub, noise, ring mod) through a 12 dB high-pass and low-pass with their own envelope, up to four drifting unison voices, then a tape stage — wow and flutter on the pitch, chorus, saturation, age (worn top and bottom, the odd dropout) and hiss. 13 presets.
- **Drum kits.** File ▾ → **Drum kits…** (or ⚙ Settings → Kit) puts a CR-78-, 808-, 606-, 909-, 707-, 727- or 505-style kit, or a clean acoustic kit, on pads 1–8, keeping the synth slots. Every sound of each machine (97 in all: congas, claves, cowbells, toms, the 727's whistles and quijada, the CR-78's guiro…) is in the pad's Presets list, one group per machine. They are synthesized from layers, no samples, with pitches, sweeps and decays tuned against measurements of the original machines.
- **…pump synths** (26 Oct). Three of the …pump plugins' instruments as synth engines, group *…pump* in the engine list: **Mono** (pump MONO: three oscillators with sync and FM, Ladder 24 / SVF 12 / Diode 18 / Sallen 12 filters, 2x oversampled), **Poly** (pump POLY: two oscillators, poly-mod, four filter voicings, unison, chorus) and **Coil** (pump COIL: SPRING's tanks as tuned springs kicked by the note). The plugins' own DSP (`pump/synth/pump-synth.wasm`), their parameters and factory presets, so a pad matches the plugin with the same values; C-4 plays the plugin's MIDI note 60. They render like the other engines (a note, re-pitched for the rest); **Hit** is how hard that note is played. Built in the pump repo by `wasm/build.sh`. Each also comes **live** (26 Oct): **Mono live**, **Poly live**, **Coil live** play the plugin in the tracker as a DAW would: every note its own pitch (no re-pitched recording, so envelopes and the filter stay put across the keyboard), the VOL column as velocity, notes as long as they're held, slides and bends as pitch bend, MONO's glide and legato, POLY's chords through its own voices. A live engine shares its values with its rendered twin (switch between them and the sound stays). Safety net: if the device can't keep up (dropouts while they play), they switch to their renders until a reload, and say so; an export always plays them live.
- **LXR-02 voices** (`lxr/`, GPL-3.0, optional). The LXR-02 drum machine's own firmware voices, compiled to run here: **Firmware drum**, **Firmware snare**, **Firmware cymbal** and **Firmware hat** in the engine list (group *LXR-02 firmware*), with the machine's 0–127 knobs on its own pages (oscillator, envelope, pitch envelope, velocity, FM or mod oscillators, transient, filter, LFO, level) and its value names. **File ▾ → Import LXR kit (.snd)…** puts a kit from the machine's SD card on seven pads (drums 1–3, snare, cymbal, closed and open hat). Without the `lxr` folder the app runs as before. See [`lxr/README.md`](lxr/README.md) and [`lxr/NOTICE.md`](lxr/NOTICE.md).
- **Acoustic kits.** Funk (dry and tight), Studio (bigger and brighter) and Jazz (small tuned-up kit, ride, brushes): 38 synthesized acoustic drum sounds with beater and stick attack, each kit with a softer ghost snare for ghost notes. They are in the Drum kits… list and in the pad Presets list.
- **Funk breaks.** File ▾ → **Funk breaks…** loads one of twelve original breaks in the classic funk style (84–112 BPM), with swing, ghost notes, open-hat lifts, a fill in the fourth bar and a laid-back snare built in. Choose **New song with this break** to get its tempo, swing, acoustic kit and a light compressor / room / tape chain on the master, or **Add to this song** to drop its four bars in after your song. Each part is on its own track (kick, snare, ghosts, hats, toms, crash) as ordinary phrases, so you can edit any of it.

**Pad effects.** Each pad can have up to 6 effects, run top to bottom after the layers: EQ, Compressor, Reverb and Tape delay (Airwindows EQ, Pressure4, Galactic and TapeDelay2, the same as the tracker's track effects), Rings, Clouds, Saturation, Tape, Chorus and Bitcrush. Each effect card has a level meter showing the peak coming out of that effect while the pad plays, with the last peak in dB beside it. Reverb and delay keep the dry hit at full level until their Mix passes the half-way point.

## Settings

The top bar has two menus that work like ...Seeds': **File ▾** and **⚙ Settings ▾** each open a dropdown under the button. Only one is open at a time; tap outside it, tap the button again, or press Esc to close it.

- **File ▾**: Save project, Save as…, Open project…, Open recent… and Restore a backup…, with their keyboard shortcuts (plus Export / Import chains; on the …waves and …chains screens it drives that patch instead). A dot on File ▾ (and before the song's name in the window title) means the song has changes that aren't in its project file yet.
- **View ▾** and **Audio & MIDI ▾** (Desktop only): on a computer the long Settings list is split in three. View has the screen, Arrange, skin, text size and the panel switches (keypad, bottom panel and its parts, stage); Audio & MIDI has the output, latency, rate and MIDI; Settings keeps the song, input, render, mastering, kit and app. On Mobile everything stays under the one gear.
- **Settings sheets.** The long lists open in their own window, like the preset browser: **Screen settings…** (text and colour, layout and panels, the Phrase screen, the Song screen) and **Skin…** in the Screen part of the menu (View on Desktop); **Song settings…** (name, tracks, tempo, groove, pattern length, the song's impulse responses) and **Input settings…** (PAD or KEYS, note on entry, edit step, sticky keys, commands) in Project. Each window has a search box and tap-to-open groups. The menu keeps what you change mid-session: Text size, Simple phrase and Follow. **Skin…** shows every skin as a little tracker in its colours; tap one to try it on the app straight away, **Done** keeps it, **Back to …** returns to the skin you had.
- **⚙ Settings ▾**: one scrolling list with a section per topic, ruled off from each other: **Kit** (save, load, factory, clear), **MIDI**, **Export**, **Skin** and **Audio**. On the tracker, a **Project** section comes first with everything on the Project screen as touch controls (checkboxes, dropdowns, sliders with − and +, buttons), grouped into Input, Screen, Song, Render, Project file and App. On the …waves and …chains screens a section for that patch comes first instead. The Project screen is still there and changes the same settings.

**Colourful boxes.** Everything you press at the bottom of the screen uses the look of the tracker's PAD-mode nav pad: a darker grey panel, each button in one of the screens' pastels on a white offset block. That's the nav pad, the command row, the KEYS-mode keypad (PLAY is always green, sharps stay black) and the 16 pads on the synth page.

**Audio** picks the output device (Chrome, Edge and the desktop app on a computer; Android plays through the system's output, so pick it in the system's media output switcher), the overall level, the latency (Lowest, Balanced or Safest, for when you hear crackles) and the sample rate (Device, 44.1k or 48k). The output and level change at once; latency and rate need **Restart audio**, which reloads the app with your song and kit kept. **Show device names** appears when the browser only numbers the outputs (it asks for the microphone once, just to get the names, and closes it). **Test sound** plays a short tone.

**Tracker display settings** (in the menu and on the Project screen):

- **Hide chains page** (on by default) hides the chain screen; see Tracker below.
- **Display steps as decimal** (on by default) numbers the rows in decimal: song rows 000–255, phrase rows 00–31, sect rows 00–15, the arrange overview too. Off shows hex. Phrase, sect and instrument numbers and values stay hex.
- **Play note on entry** (on by default) auditions the instrument as you type a note into the phrase editor, so you hear what you enter. Off makes note entry silent.
- **Show on-screen keypad** (on by default) shows the KEYS-mode keypad at the bottom for tapping in notes. Off hides it; the computer keyboard still types, and the octave (OCT, top bar) stays. PAD mode is unchanged.
- **Show instrument list** (off by default) lists the 16 instruments with the pad each plays (or its MIDI channel), long names cut short. It sits in the grey side panel; where there's no side panel, it goes between the arrows and the buttons in PAD mode when there's room. Tap one to open it on INST.
- **View neighboring phrases** (off by default): on the Phrase screen, a faint, read-only copy of the notes the tracks either side play at the same song row, the left track's in violet before the note column and the right track's in mustard after it, so you can see the parts around the one you're editing.
- **Follow playhead** (off by default) scrolls Song and Phrase with the playhead while the song plays; the cursor rides along and Phrase switches to whatever the cursor's track is playing.
- **Background play** (on by default): while the song plays, Android shows a playback notification with play and stop, which keeps the song going when you switch to another app. *Settings → App → BACKGROUND PLAY.*
- **Show side panel** (on by default): the grey column at the right on wide screens. Turn it off for more room.
- **Bottom panel parts:** click INST, …CHAINS or FX in the bottom panel to fold that part to a narrow strip with its name running up it (like folding a device in Ableton); click the strip to open it again. SCOPE stays at the left and TRACK at the right; they can't be folded or hidden.
- **Show classic Song screen** (off by default): the Song screen as the text grid, with Arrange beside it on wide screens, the way it was before 16 Oct. Off, the Song screen is Arrange (see Tracker below).
- **Text size** (60–200%) makes the tracker's text and lines bigger or smaller. Bigger shows fewer rows; when a line gets wider than the screen it scrolls sideways to follow the cursor.

## Skins

**Settings → Skin** (or SKIN in the tracker's settings and Project screen) switches between the ...Seeds skins: Pastel (follows your system), Pastel light, Minimal, Minimal colors, Monotone, Minimal black, Minimal colors black and Neon. The choice is remembered. **Simple rainbow** looks like the other Simple skins, but every button, key, tab, pad and tracker entry has its own colour, shifting a step on each line. **Simple rainbow dynamic** is the same with every colour drifting slowly round the colour wheel, once every 2 minutes (it stays still if your device asks for reduced motion).

## Synth page on a computer

Double-click any slider (or its name) to put it back to its default. The **◀ ▶** either side of the Engine button step through the engines in the list's order, so you can audition them one after another (each engine keeps its own settings on the pad); changing engine stops the pad's sounding notes. On a computer, an engine other than Layers shows its own controls in the middle under the Engine row (where Layers has its layers), and the right-hand column has its effects and the **sound view**: a spectrogram of the pad's sound (time across, 20 Hz–20 kHz up; tap it to play), with a line that runs across it while the pad plays (from the pads, the keys, MIDI or the song), and a scope of the output under it. **Pad effects** (the Effects card) now work on every engine that plays its render — Blip, Piano, Tine EP, Organ, Modal, Strings, Partials, SoundFont and the rest — after the engine; Bass, Voice, Acid and Machine play live in the song, so they stay dry (put effects on their track instead). The meter at the top right of the pad header shows the level of what you play on this page (pads, the keys, MIDI); past the 0 dB line it turns red. Everything played live goes through the same safety limiter as the song (Project → LIMITER), so a big chord on the Piano, Tine EP, Organ or any other engine is held down instead of clipping. The limiter is a brickwall one (3 ms lookahead, true-peak, never past −1 dBFS) for playback, the Synth page and renders alike.

With Settings → App on Desktop and a window at least 1100 px wide, the synth page splits into three columns: the 16 slots as a list at the left (Drums, then Synths; click one to pick and hear it, as with the pads), the sound in the middle (name, waveform, voice controls, layers and the layer editor), and the pad's effects and the voice pitch, filter and amp controls in their own scrolling column at the right, so they stay in view while you edit layers. The keyboard works as before. A narrower window, or Mobile, shows the usual single column with the pads at the bottom.

## Synth slots

The kit has 16 slots to start, and up to 64: **SLOTS** at the top of the Synth page (− and + step by 8; tap the number to type one). New slots start as simple synths; fewer slots only hide the last ones, and their sounds come back when you add slots again. **THIS SLOT** sets how the selected slot plays: **ONE-SHOT** plays its whole sound (a drum), **HELD** sounds until note-off (a synth). The count and the kinds are kept in the kit. Instruments 10 and up that nothing uses yet follow the count, so instrument N plays slot N. By default 1–8 are the drum pads (one-shots) and 9–16 are synths for melodic and harmonic parts, starting as Bass, Pluck, Keys, Pad, Lead, Bell, Organ and Sub. A synth note holds at its sustain level for as long as it is held (up to the slot's Max len), then fades over the longest release of its ADSR layers. They are tuned so C-4 plays middle C. **A voice per track** (⚙ Settings → Kit → "A voice per track", off by default) grows the kit past 16 slots: every song track gets its own pad — a drum one-shot on mono tracks, a simple held saw synth on poly tracks — so the 16-voice limit no longer applies. The pads stay the same size and the dock scrolls up and down to reach them. On the synth page, the computer keyboard and the pads hold synth notes while pressed (hold several keys for a chord); Space and Shift+number play them for the slot's Gate; MIDI notes that aren't mapped to a drum pad play the selected synth, held until note-off. Exports still make one-shots (the Gate length), named with their note if you turn that on. Kits saved before the synth slots load with the factory synths in 9–16.

## Playing pads from the computer keyboard

On the synth page the keyboard plays the selected pad chromatically: Z to / is the lower octave (S D G H J for sharps), Q to P the upper (2 3 5 6 7 9 0 for sharps). C-4 is the pad at its own pitch; − and = (or numpad / and *) change the octave. Shift+1–8 or ◀ ▶ pick a pad (◀ ▶ go through all 16 slots; on a computer, where they're a list down the left, ▲ ▼ do too), Space plays it as it is. On a synth slot, notes hold while the keys are down.

## Tracker

Press **?** (or F1, or the **?** button at the top right) for a help screen with every key and a guide to how the tracker works.

Tap **Tracker** at the top for a sequencer that plays the kit. 16 tracks:

- **Song** – 256 rows × 16 tracks of sect numbers (up to 32, or 24 with a voice per track: Settings → Song → Tracks; Song and Mixer then show as many tracks as fit and scroll sideways with the cursor, or by swiping left and right). Each track loops back to the top of its block of filled rows when it reaches an empty row.
- **Sect** (a section; M8 calls it a chain) – up to 16 phrases in order, each with a transpose.

**Sects are hidden by default** (Settings → Hide sect page, or Project → SECT). The song then works like a pattern sequence: EDIT×2 (Enter×2) on an empty song cell makes a new block that already holds one phrase (numbered the same when that's free), and SHIFT+▶ goes straight from the song to that phrase. EDIT×2 on a filled block makes a unique copy of it and its phrase. Nothing is deleted: set CHAINS to SHOWN and the chain screen is back, with everything in it.

**The Song screen is Arrange** (new, 16 Oct). On every screen size, the cover screen included, the Song screen draws the song as Arrange's blocks instead of the text grid: one row of blocks per song row, one column per track, and the amber **MST** column at the right. Nothing about using it changed: the same cursor, keys, pad and command buttons, hex typing, EDIT×2, CLN / CLN↓, selecting, copy, cut and paste, M to mute, SHIFT+◀▶ to change screens. Tap a block to put the cursor on it, tap it twice to open its phrase, hold it (or Alt-click) to mute it. On a wide screen the blocks stop growing at about 44 px so the dancing dogs keep their place beside it. On the other screens Arrange moves back to its place at the right, as below. **Settings → Show classic Song screen** (off by default) brings back the text grid exactly as it was.

**Song screen extras (Oct 2026).** Each can be switched off in Settings (View on a computer), and the song stays the same either way.
- **Mouse:** drag across empty cells to select blocks (Shift-click one block, then Shift-click another to select everything between; Shift-drag selects starting on a block too), drag a block (or the selection) to move it, hold Alt (Option) while dragging to copy it, and right-click for a menu (copy, cut, paste here, clone, clone down, mute, loop these rows, open the phrase, name a section, clear). *SONG MOUSE.*
- **Sections:** the **SECT** lane left of the row numbers names runs of rows (INTRO, VERSE, DROP…). Tap the dashed **+** on the cursor's row (or tap the empty lane, double-click it, or right-click a block) to name the section starting at that row; tap a name to go there; hold or right-click a section to rename, loop or remove it. The lane is only as wide as its longest name (narrow while there are none, 21 Oct), so the grid stays centred on the phone. The info line names the section the cursor is in, and the Pattern view shows it. Wide screens. *SECTIONS.*
- **Loop by dragging:** drag down the row numbers to loop those rows (LOOP shows them; PLAY on the Song screen loops them). A tap still plays from that row. *LOOP DRAG.*
- **Phrase peek:** beside the Song screen, a DOGS | PEEK switch shows the phrase under the cursor instead of the dancing dogs (the dogs stay the default). *SONG PEEK.*

**Paging into Arrange from Phrase.** With the Arrange panel beside a phrase, click or tap it (or SHIFT+◀, or the SONG tab) and it takes the keys, the SONG tab lights and the phrase fades back: arrows, hex, EDIT, CLN, M and the rest work on the song cursor there, and the phrase follows the block under the cursor (PIN in the panel's header stops that). Tap the phrase, SHIFT+▶ or Esc to give the keys back; a second tap on the SONG tab opens the Song screen. On the folded phone, a three-row **song strip** over the phrase does the same: tap it, then move through the song with the arrows. *Settings → ARRANGE FOCUS, SONG STRIP.*

**Pattern view.** On a wide screen the Phrase screen's title line has PHRASE | PATTERN: PATTERN shows every track's phrase for the current song row side by side (Renoise-style). You edit the open track's phrase as usual; the arrows carry on into the next track's phrase, Tab jumps a track, Ctrl+↑↓ (or [ ]) steps song rows, and SHIFT+▶ goes back to the plain phrase. It warns when a track's phrase is a different length (it runs ahead or behind from there). FX2/3 and empty tracks fold away (buttons in its bar). *Settings → PATTERN VIEW.*

**Simple phrase screen.** For bigger, easier-to-read notes: the Phrase screen on its own, as large as it fits, with no Arrange beside it, no song strip over it and no piano down the side. At least ten rows show, and the rest scroll with the cursor. TEXT SIZE still makes it bigger or smaller. Off by default; other screens are unchanged. *Settings → SIMPLE PHRASE (Show simple phrase screen).*

**Arrange.** On a wide screen (the Fold unfolded, a tablet, a computer) a blue song overview sits at the left of the tracker, so SHIFT+◀ goes left to the song and SHIFT+▶ right to the phrase (*Settings → ARRANGE SIDE* puts it back on the right): every filled song row as blocks, one column per track, with the playing rows lit. Tap a block to go to it (from the Phrase screen it opens that block's phrase), tap it twice to open its phrase, and tap a row number to play from there (tracks are muted in the Mixer). **Alt-click or hold a block to mute it**: it stays on the song with its phrase, just silent, so you can drop the hi-hats out of a section and bring them back without touching the phrases. **Pinch to zoom** (or Ctrl+wheel, or **−** / **+** in its header) to make the blocks up to 3× bigger so one is easy to hold; swipe sideways to move across the tracks, and **○** fits every track in the panel again. On a computer the zoom goes in smaller steps, stops when blocks are about 84 px wide, and keeps the selected block where it is on screen. The zoom is remembered. Muted blocks are struck through on the Song screen too, and M toggles the block under the cursor in KEYS mode. Drag the grip on its left edge to make it wider (the blocks get bigger with it), or double-tap the grip to jump between big and normal; it remembers the size. Project → ARRANGE: AUTO (the default) shows it when the screen is at least 600 × 500, which includes the Fold 6 unfolded in either orientation; ON shows it at any size; OFF hides it. Its info line shows this screen's size.
- **Phrase** – up to 32 rows of note, volume, instrument and three effects. **ROWS** (− 16 +, at the right of the tab bar) sets how many rows the open phrase plays, 1–32; tap the number to type one. On the Sect screen it changes the phrase on the cursor's row. The number you pick also becomes the song's PATTERN LEN, so the next new phrase starts at that size. Tap LEN on the phrase's title line for the same LEN plus LPB (lines per beat for this phrase; -- uses the song's). ▲ on the top row wraps round to the last row and ▼ on the last row to the top (Pattern view too); the rows scroll to follow.
- **Inst** – 16 instruments. Each plays one of the kit's slots (drum pads 00–07, synths 08–0F, more with a voice per track) with its own transpose, volume, pan, reverse and start point. C-4 plays a pad at its own pitch.
- **Mixer** – volume, pan, mute, solo and effects per track, level meters per track (green, yellow above −12 dB, red above −6 dB), and a stereo master meter with peak and CLIP.
- **FX** – up to 4 effects per track and 4 on the master, running live as the song plays (see below).
- **Project** – tempo, LPB (lines per beat: 4 = 16ths, 8 = 32nds, 3 or 6 = triplets; new songs start at 8), TICKS (ticks a step, 6 by default), PATTERN LEN (how many rows a new phrase starts with, 16 by default, and it follows the last ROWS or LEN you set; ALL PHRASES TO sets every phrase to it), swing (MPC-style: SWING sets the amount, 50% straight to 75% max, 66–67% the triplet feel; SWING NOTE sets the beat — 8ths, 16ths, Triplet, wider dotted grids), limiter, render settings, renders, and project files (song and kit together).

**Chords and polyphony.** The second half of the tracks is polyphonic, whatever the track count (9–16 with 16 tracks, 17–32 with 32; with an odd count the mono half gets the extra one), and the first half plays one note at a time. On the Song and Mixer screens one pink box labelled MONO surrounds the mono tracks (always on the left) and one green box labelled POLY surrounds the polyphonic ones (always on the right), each label giving its track range; in Phrase the note column takes the open track's colour. A phrase opened from one of them shows four note columns (N1–N4), so a row can hold a chord, and notes ring over each other up to 4 per track (a fifth steals the oldest). A note OFF in any note column releases every note on the track; on synth slots that's their release, drum pads stop at once. Tracks 1–8 stay monophonic and play only N1. Instruments 08–0F play the synth slots in new songs (older songs keep their instruments as they were). Songs saved before the chord columns open with their notes in N1.

**FX column.** Sequencer commands. EDIT on an FX cell opens a list of them under headings by what they do (Volume and pan, Pitch and arpeggio, Note timing, Sound, Chance and random, Effects, Tempo and groove, Play order, MIDI), as the FX slot's effect list is; a master phrase lists only its own commands, the same way:

| | | | |
|---|---|---|---|
| `ARP` arpeggio (+X, +Y semitones) | `ARC` arpeggio pattern (X: up, down, up-down, random) and speed (Y ticks) | `CHA` chance the note plays | `DEL` delay in ticks |
| `GRV` / `GGR` groove: X ticks on even steps, Y on odd | `HOP` end the phrase, next one starts at row Y | `INS` play with instrument XX | `KIL` stop the note after XX ticks |
| `OFF` fade the note out after XX ticks | `NTH` play on pass Y of every X | `RET` retrigger every Y ticks, X fades | `REP` repeat the last command, adding XX |
| `RND` randomise the command to the left (alone: the note's pitch), −X / +Y | `RNL` the same as a random walk | `PSL` pitch slide | `PBN` pitch bend across the step |
| `PVB` vibrato (X speed, Y depth) | `SED` seed the random numbers | `TPO` tempo from this row on | `TSP` transpose the track from here on |
| `TIC` ticks a step from this row on (00 goes back to the project's) | `CCA`–`CCD` MIDI CC (00–7F) to the instrument's CC slot | `PGM` MIDI program change (00–7F) | `CSL` the row's CC commands glide over XY ticks (00: the step) |
| `DIR` play direction from the next row: 00 forward, 01 backwards, 02 ping-pong, 03 random | | | |

Instrument commands: `VOL` volume, `PIT` pitch (signed semitones), `FIN` fine tune (cents), `PLY` 00 forwards / 01 reversed, `STA` start point, `PAN`. On a row with no note they change the note that is already playing (so do `ARP`, `PBN`, `PVB`, `KIL` and `OFF`). There are 6 ticks to a step unless Project → TICKS or a `TIC` command changes it. Not here yet: tables (`TBL`, `TBX`, `THO`), `SNG`, `NXT`, `RTO`, `PVX` and filter commands. `GRV` sets the groove of its own track; `GGR` sets it for every track. Songs from earlier versions are converted on load (`CUT` becomes `KIL`, `OFS` `STA`, `REV` `PLY`).

**Track effects.** Open FX from the tab, from the mixer's FX row (EDIT), or with SHIFT+▶ in the mixer (on the MASTER row it opens the master chain). On the mixer's FX row, OPTION (Alt in KEYS mode) + ▲▶ turns a track's effects on in order, up to four, and OPTION + ▼◀ turns the last one off without losing its settings — turn the count back up and it returns; with none on, slots fill from 1. Each track has 4 slots that run top to bottom; EDIT on an empty slot adds an effect, EDIT+arrows picks another type, OPTION+EDIT removes it. The settings of the slot you were last on are listed underneath, as hex values like the rest of the tracker. The effects:

- **EQ** – Airwindows EQ: treble, mid and bass, their frequencies, lowpass, highpass, output
- **COMP** – Airwindows Pressure4 compressor, with a mix control for parallel compression
- **VERB** – Airwindows Galactic reverb
- **DLY** – Airwindows TapeDelay2, timed in steps so it follows the tempo
- **SAT** – Airwindows Density · **TAPE** – Airwindows ToTape6
- **CHOR** – DaisySP chorus · **CRSH** – DaisySP bitcrush
- **RING** – Mutable Instruments Rings resonator · **CLDS** – Mutable Instruments Clouds

Renders include the effects and let reverb and delay tails ring out. Stems skip the master effects and the limiter, so they add up to the mix when the master chain is empty. Each effect costs some phone CPU; Clouds and Rings are the heaviest. The **CPU** meter in the top bar shows the load (Chrome's own audio load where it reports one, otherwise the share of real time the track effects take); it turns gold past 50% and red past 80% or on dropouts. Tap it to see which tracks cost the most.

**One finger is enough.** Every button combination works without holding two buttons:

- **Sticky keys** – tap SHIFT or OPTION on its own and it lights up and stays on for the next button (tap it again to cancel). So SHIFT, then ▶ changes screen; OPTION, then EDIT clears; SHIFT, then OPTION selects; SHIFT, then EDIT pastes; SHIFT, then PLAY plays the song. Holding still works as before.
- **Command row** – a row of buttons above the d-pad: − − / − / + / + + (change the value), ◀ PREV / NEXT ▶ (other chain, phrase, instrument or FX track), CLEAR, SELECT, COPY, CUT, PASTE and ▶ SONG.

Both are on by default on touch screens and can be turned off in Project (COMMANDS, STICKY KEYS).

**Two input modes** (⚙ Settings → Input, or Project → INPUT):

- **PAD** – a d-pad plus SHIFT, PLAY, OPTION and EDIT, used like this: SHIFT+arrows changes screen, EDIT adds (twice for a new chain or phrase), EDIT+arrows changes a value, OPTION+EDIT clears, SHIFT+OPTION selects, SHIFT+EDIT pastes, and OPTION+arrows go to the nearest block that way on the song (on the Song screen, in Arrange, and from a phrase, which then opens that block's phrase; Settings → PATTERN NAV off gives the old OPTION+arrows back). On a computer keyboard: arrows, Shift, Z = Option, X = Edit, Space = Play.
- **KEYS** – direct entry. On a keyboard: notes on Z–M and Q–I, `-`/`=` octave, `1` note off, 0–F for hex, letters for effects, Enter to add or open (on a phrase row it also picks up what's there as the current values: the row's instrument, plus the note, volume, or effect and its value under the cursor, which new entries then use; the hint line shows them after NOW), Delete to clear, Ctrl/⌘+arrows to change values, `[` `]` for the previous/next chain or phrase, Ctrl/⌘ B, C, X, V to select, copy, cut and paste. On a touch screen the dock turns into a keypad that follows the cursor: a piano in the note column, 0–F in hex columns, effect names in effect columns.

**Computer keyboard** (KEYS mode):

- **Screens:** Alt+1–7 for Song, Sect, Phrase, Inst, Mixer, FX, Project, Alt+0 the synth, Alt+8 …waves, Alt+9 …chains and Alt+` back to the last view (from any of them, …waves and …chains included); F2 Phrase, F3 Mixer, F4 Inst. Alt/⌥+◀▶ step through every screen in tab order (Song, Sect, Phrase, Inst, Mixer, FX, Project); Alt/⌥+▲ goes to Project, Alt/⌥+▼ to Mixer.
- **Transport:** F5 plays the song from the top, F6 this screen, F7 the song from the cursor row, F8 stops. Space plays this screen (on a bus’s phrase or sect, its song row with every track that feeds it, looping), Shift+Space the song, Ctrl+Space just this pattern, looped (turns LOOP on; again stops; Alt+L turns LOOP off). On a Mac ⌘+Space is Spotlight, so it's Ctrl+Space there too. Ctrl/⌘+D duplicates as Renoise does: on the Song (or Arrange) the pattern you're on (the song row, or the selected rows) goes in again just below as unique copies; on Phrase, Mixer and FX the track goes into the next empty track of its kind (volume, pan, effects; Ctrl/⌘+Alt+D brings its notes too). Thunder's clones: Ctrl/⌘+Alt+C clone (paste puts a unique copy), Ctrl/⌘+Shift+C clone down. / mutes the track you're on and Ctrl/⌘+/ solos it (Renoise's key; again un-solos it), Ctrl/⌘+Shift+/ clears every solo.
- **Notes:** Z to ; and Q to P (S D G H J and 2 3 5 6 7 9 0 for sharps; / mutes the track, Renoise-style), 1 or Caps Lock for note off, − = or numpad / * for octave.
- **Editing:** Delete clears the whole row and steps down; Shift+Delete clears just the cell; Backspace does the same as Delete (nothing below moves); Insert adds a blank row; Ctrl/⌘+Backspace removes the row and pulls the rows below up. { and } set the edit step (how far the cursor moves after typing). Ctrl/⌘+Z undo, Ctrl/⌘+Y or Shift+Z redo.
- **Selecting and clipboard:** Shift+arrows select cells from the cursor in Song, Sect and Phrase (▲▼ up and down, ◀▶ sideways). Ctrl/⌘+Shift+▲▼ selects whole lines (the first press takes the cursor's line, the next ones grow it, and Shift+▲▼ then grows it too); on a touch screen, tap the row numbers instead. Ctrl/⌘+C copies, Ctrl/⌘+X cuts, Ctrl/⌘+V pastes at the cursor row (or over a selection, from its top), Ctrl/⌘+A selects every line, Ctrl/⌘+B starts a block selection, Esc drops it. Lines copied in one phrase paste into any other phrase. A paste or cut undoes in one step.
- **Files:** Ctrl/⌘+S saves the project, Shift+Ctrl/⌘+S saves it as a new file, Ctrl/⌘+O opens one, Ctrl/⌘+N starts a new song (keeps the kit; asks first if there are unsaved changes; in a browser tab the browser keeps Ctrl+N for a new window, so it works in the desktop app) (these work on the synth page too). In desktop Chrome and Edge, Save writes straight back to the file you opened or last saved; other browsers download a copy, and Save As asks for a name first.
- **Moving:** Tab and Shift+Tab jump between the note, volume, instrument and FX columns (or tracks); Home, End, Page Up/Down; [ ] for the previous/next chain or phrase; Shift+Alt/⌥+arrows for the phrase above, below or beside it on the Song grid.

These screen, transport and undo keys also work in PAD mode.

**Tempo and ticks.** In KEYS mode, **OCT − / +** beside ROWS sets the octave for typed and keypad notes (tap the number for octave 4). Beside ROWS, the tracker shows the tempo and the ticks a step. While it plays they follow `TPO` and `TIC` (in gold), and the dots light up tick by tick through each step. Tap them for a reminder of where to set them.

**On a phone** the tabs take the first line under the top bar, with tempo, ticks and ROWS on the second. The buttons under the screen are taller for thumbs, and the screen's text shrinks as needed so 16 rows always fit.

**Moving a project between phone and computer.** Project → SHARE PROJECT (on phones) sends the project file, song and kit together, to Drive, Gmail, Quick Share or any app on the share sheet. On the other device, Project → LOAD PROJECT (Ctrl/⌘+O) opens it. SAVE works too: it downloads the `.thunder` on a phone, and writes straight back to the file on desktop Chrome and Edge, so you can keep one file in a synced folder. On Android, tapping a `.thunder` attachment can’t offer a web app (a PWA can’t claim a custom extension in Android’s Open with), so share the attachment to ...Thunder Plus from the email app, or download it and use LOAD PROJECT; its picker shows every file.

**Screen colour.** Every tracker screen has its own pastel, on its tab and its button in the side map: Song blue, Sect lilac, Phrase mint, Inst peach, Mixer butter, FX pink, Project aqua. Project → SCREEN set to BY SCREEN (the default) colours the screen to match; or pick one pastel for all of them (blue, lilac, mint, peach, butter), or black. The pastels use dark text at readable contrast.

On touch, tap a cell to move there, tap it again to open or add, and drag up or down on the cursor's cell to change the value. Drag a finger up or down anywhere else on the screen (between or beside the lines, the title, the info lines) to scroll through the rows; sideways too when big text makes the lines wider than the screen. Tap a track number to mute it.

**With a mouse** the tracker grid (Phrase, the Pattern view's open track, Sect and the classic Song grid) works like Renoise's pattern editor (21 Oct). Touch is unchanged.
- **Drag** to select a block (from any cell except the cursor's own filled one). Dragging past the top or bottom of the grid scrolls on. The wheel moves a row per notch.
- **Shift-click** selects from the cursor to where you click; Shift-click again to grow or shrink it. A plain click outside the selection lets it go.
- **Drag a selection** to move it; hold **Alt** (Option), **Ctrl** or **⌘** as you let go to copy it. It overwrites what's under it, as paste does, and undoes in one step. On Phrase it goes sideways only onto columns of the same kind (notes to notes, effects to effects). Esc while dragging puts it back.
- **Drag the cursor's cell** to change its value, as before; hold **Shift** while dragging for big steps (an octave on a note, 16 on a number).
- **Right-click a track number** (Song, Mixer, Arrange's header) **or a meter** to solo the track, again to un-solo it; a click mutes. Arrange's track numbers mute and solo with a mouse only, so a slip on the phone can't silence a track.
- **Pattern view's track bands** (the number and name over each track): Alt-click mutes the track, right-click solos it, a double-click names it; a plain click still opens it.
- **Arrange:** middle-click a block to mute it (or the whole selection it's in), Alt-drag *or* Ctrl/⌘-drag copies, and on the Song screen a double-click on an empty cell starts a new phrase there and opens it.
- **Synth sliders:** right-click one for Reset, Type a value… and Learn a MIDI knob for it; the wheel nudges the slider you clicked last (Shift+wheel in fine steps); Shift-drag moves it a tenth as fast. (The settings menus' sliders stay locked against stray touches.)
- **Drop files on the window:** audio on a pad loads into that pad (anywhere else, the selected pad); a `.thunder` / `.json` project opens, a kit file loads, a `.mid` imports, a …chains patch imports.
- **…chains and …waves:** double-click an empty spot of the patch, type part of a module's name and press Enter to add it right there.

**Track names and colours** (21 Oct). Double-click a track number (Song, Mixer, Arrange, a meter, the Pattern view's band, the Phrase title or the bottom panel's TRACK strip), or Edit ▾ → **Name this track…**, for a name of up to 12 letters and a colour. They show on the Phrase and Pattern titles, Arrange, the Song and Mixer headers, the meters and the bottom panel, and name the stem files (`Song 02 Kick.wav`). They're saved with the song.

**Selection tools** (21 Oct, Renoise's Advanced Edit), in Edit ▾ and the right-click menu on a phrase. Each is one undo step and works on the selection, or the whole phrase:
- **Interpolate:** a ramp between the values on the first and last selected rows, in each volume and effect column selected (an effect needs the same command at both ends).
- **Volume…:** scale by a percent, fade in, fade out, or set every note's volume (an empty volume counts as FF).
- **Instrument…:** set every note to one instrument, or swap two.
- **Shrink** (every other row, double time) and **Expand** (spread out, half time); what would land past the end is left out and the toast says so.
- **Mix-paste** (Ctrl/⌘+Shift+V, every grid screen): like paste, but only into empty cells.

**Render a part** (21 Oct, Renoise's Render To Sample). Edit ▾ (or File ▾) → **Render … to a slot…** renders the phrase selection (or the whole phrase), or on the Song screen the selected blocks (or the cursor's song row), into a kit slot as its sample: pick a slot this song doesn't play, the current one or any other. The slot's other layers are turned off (undo brings the sound back) and an instrument is set to play it. **Render … as a WAV** saves the same part as a file. A phrase renders its track alone without the master's effects; song rows render with the master column, effects and limiter. Tempo changes from earlier rows aren't carried in.

**Project files** (21 Oct). Projects save as `.thunder` files (the same JSON inside; `.json` projects still open). The app remembers the file you saved or opened, so Ctrl/⌘+S goes back to it after a restart too (in Chrome or Edge the browser asks once to allow it; on a phone it downloads a copy), and File ▾ → **Open recent…** lists the last eight. New song, Open, Load demo, a break's new song and Restore ask **Save changes?** first when there's anything unsaved. Every 3 minutes while you work (and before anything replaces the song) the song and kit are backed up in the browser, the last 10: File ▾ → **Restore a backup…**. In the desktop app, closing the window asks too, a `.thunder` file opens with a double-click, and saves are written safely (to a temporary file first, then swapped in).

**Rendering.** Project → RENDER SONG saves a stereo WAV; RENDER STEMS saves a zip with the mix plus one WAV per track. Stems are all the same length and include each track's effects; they skip the limiter and the master effects. Rate, bits and normalising follow the Export settings.

The tracker keeps playing while you switch back to the synth, so you can change a pad and hear it in the loop.

## Running it

It's a plain web app with no build step: `index.html`, `manifest.webmanifest`, `sw.js` and the `icons` folder. Turn on GitHub Pages for this repo (Settings → Pages → deploy from `main`, root folder), then open **https://matthettich.github.io/thunder-plus/** in Chrome.

## Install it

- **Android (Chrome):** open the address, tap **⋮** → **Install app** (or **Add to Home screen**).
- **Mac / PC (Chrome or Edge):** click the install icon in the address bar.

It opens full screen with its own icon and works offline once it has loaded. To update, push a new `index.html`. The installed app has no pull-to-refresh, so it checks for a new version whenever it opens or comes back to the front and shows a **New version ready · tap to update** button; Project → UPDATE APP reloads with the newest version any time. Your song and kit are kept.

## Desktop app (Electron)

The `electron` folder wraps the same app as a desktop program for Windows, macOS or Linux. It runs from its own
`app://thunder/` address (not plain files), so the …waves and …chains editors, the mastering engine and the bass
engine load their audio worklets as they do on the web. Songs and kits are saved inside the app (separately from
the browser's copy); use File → Save to move work between them. Project files are `.thunder` files: the installer
makes them open in the app with a double-click (also from the Mac's Finder; not the Windows portable .exe), and closing
the window with unsaved changes asks Save / Don't save / Cancel.

**Updates.** Installed copies check GitHub Releases when they open (and every few hours): on Windows and Linux
the new version downloads by itself and asks to restart; on a Mac (unsigned) it says a new version is out and opens
https://github.com/matthettich/thunder-plus/releases/latest, which is also the link to give testers. To ship one,
open **Actions → Desktop app → Run workflow**, type a version (e.g. `1.1.1`) and run it, or push a tag:
`git tag v1.1.1 && git push origin v1.1.1`. The workflow sets the app's version from the tag,
builds everything and publishes the release.

**Option A: build on GitHub (no setup).** Push the repo, then on GitHub open **Actions → Desktop app → Run
workflow**. When it finishes (about 10 minutes), the run's page has three downloads: the Windows installer and
portable .exe, the Mac .dmg (Apple silicon and Intel in one), and a Linux AppImage. A version tag (above) also publishes them as a release.

**Option B: build on your computer.** Install [Node.js](https://nodejs.org) (the LTS version), then:

```
cd electron
npm install
npm start            # run it without building an installer
npm run dist:win     # Windows installer + portable .exe  → electron/dist   (on Windows)
npm run dist:mac     # macOS .dmg                         → electron/dist   (on a Mac)
npm run dist:linux   # Linux AppImage                     → electron/dist
```

`npm start` and the `dist` scripts first copy the page, the worklets, fonts, icons and the two editors into
`electron/app` (`copy-app.js`), and stop if a file the page loads is missing, so the desktop app always matches
the site. To update the desktop app later, pull the latest code and build again (bump `version` in
`electron/package.json` so the installer replaces the old one cleanly).

The builds aren't code-signed:

- **Windows:** SmartScreen asks the first time: More info → Run anyway.
- **Mac:** right-click the app → Open the first time. If macOS says the app "is damaged" (it does that for
  unsigned apps downloaded from the internet), run `xattr -cr "/Applications/Thunder Plus.app"` in Terminal once.

MIDI, the save/open dialogs and the output-device list are allowed; audio keeps playing with the window in the
background; opening the app twice brings the open window forward.
