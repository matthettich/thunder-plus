# Usage census (A7)

Generated by `node native/tools/census.mjs <songs folder> --md ...` (tool: `native/tools/census.mjs`, test:
`native/tests/census.test.mjs`, which also checks the tool's command list against `index.html`). The songs are read as
data only and are not committed. Rows are sorted by use, most used first: the manager reorders units inside a stage by
this table (NOTE: only **two** songs so far, the owner's `acid.thunder` (build 589, 38 tracks) and the factory demo
`sounds/ELECTRO.thunder` (build 296). Re-run on the owner's whole folder before ordering N1 / N3; the command is one
line.)

How to read it: "Uses" counts slots / voices / rows. "Switched on" is how many of those slots have `on` true. Layer
types are counted only for voices that play their layer stack (no whole-voice engine) and only for layers switched on.
Pump types are effect slots that carry a `pump` object plus pump synth engines (`synth:`). "layers (layer stack)" is a
voice with no `engine` field. Tracker commands are every command cell in every phrase (`FXC`, index = code); unknown
codes are printed as such. Samples: both songs have none embedded (every sound is synthesised); `acid.thunder` and ELECTRO
have no SoundFont voices.
