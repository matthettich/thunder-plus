## Decisions
- Item 1: fixed rather than only documented because the fix is one condition and gives the header a true guarantee (estimate <= real). The web's own rule for an unknown-length render is `ceil((max(seq.time, last note end) + 0.05) * sr)`; native now ends at `max(seq end, last voice end)` without the web's extra 0.05 s. Not changed (a 50 ms difference of trailing silence, only for songs whose voices end before the sequencer does).
- Item 4: see the table (`SeqStep::bpm0`; the lead ruled this after verify-267 F1).
- Edits to render source: `render.h` (+1 accessor), `render_api.cpp` (the end condition, the stem-list loop). The bus-into-bus worker touches mixer / render code: expect a trivial conflict at most in `render_api.cpp` `thunder_render_stem_tracks`.
